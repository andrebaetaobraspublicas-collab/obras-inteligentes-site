Este aplicativo é destinado a estudos de concepção e pré-dimensionamento de embarcações de deslocamento. Não é um projeto executivo nem uma ferramenta certificada de aprovação naval.

Os resultados dependem da geometria paramétrica, dos pesos, dos centros de gravidade, dos coeficientes e dos rendimentos informados. Resistência e potência são estimativas; o dimensionamento estrutural normativo, a aprovação integral de estabilidade e a estabilidade após avarias, a cavitação e os efeitos de ondas/águas rasas não são verificados.

O uso em projeto ou operação exige revisão de engenheiro habilitado e atendimento aos requisitos da autoridade marítima e da sociedade classificadora aplicáveis. Não use o aplicativo como autorização para construir, carregar ou operar uma embarcação.

O núcleo funciona localmente. A leitura opcional de PDF exige conexão para carregar o PDF.js; o desenho não é enviado a servidor. Os dados ficam no navegador. Exporte o JSON para manter uma cópia independente. Limpar os dados do navegador pode eliminar projetos salvos.
