Como funciona: a atualização consulta diretamente a API pública do PNCP, mês a mês e por modalidade, e consolida apenas indicadores. O tamanho máximo da página é 50. Consultas extensas podem ser demoradas e sofrer limites do PNCP; a cobertura é indicada nos painéis. Não é necessário instalar o proxy local. Se sua rede ou a API bloquear a conexão direta, será necessário um proxy HTTPS compatível.
Interpretação dos zeros: considere a data do último dado encontrado no canto superior direito. Uma combinação sem registros só deve ser interpretada após verificar a cobertura mensal. HTTP 429 significa que o PNCP limitou a velocidade das consultas, não que o mês esteja sem dados.
